## 📌 Repository Overview

This repository documents daily progress and modular code examples across core Python concepts:

* 🐣 **`basics/`** — Documenting my foundational steps in Python: syntax notes, variable types, operators, and I/O logic that form the baseline for scripting data pipelines.
* 🔀 **`conditionalstatement/`** — Notes and solved decision-making challenges (`if`, `elif`, `else`), essential for implementing algorithmic branching and threshold filtering in AI models.
* 🔄 **`loops/`** — Hands-on problem-solving around iterative execution (`for`, `while`, `nested loops`), which directly translates to training loops, matrix scanning, and batch processing.
* 🧵 **`strings/`** — Deep-dive practice into text slicing, formatting, and manipulation methods—fundamental for text preprocessing, token handling, and NLP workflows.
* 📦 **`list_and_tuples/`** — Solutions covering structured sequences, list comprehensions, and immutable arrays, laying the groundwork for handling datasets, feature vectors, and tensors.
* 🗝️ **`dictionary_and_set/`** — Detailed notes and lookup problems on hash maps and sets, crucial for efficient $O(1)$ data retrieval, vocabulary indexing, and state tracking in ML pipelines.
