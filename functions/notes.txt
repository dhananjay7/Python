TWO TYPES OF FUNCTIONS 

1.) built-in - these are the functions which are already defined for us [A built-in function is a predefined function provided directly by the Python language that is always available to use without importing any modules or writing custom definitions.]

eg - print(), len(), type(), range()

2.) user-defined - these are the functions users (we) create while programming [A user-defined function is a custom block of reusable code created by a programmer using the def keyword to perform a specific task based on the program's requirements.]

eg - calc_sum from eg1
